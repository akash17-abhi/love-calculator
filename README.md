# Love Calculator 💕

A beautiful love compatibility calculator built with Flask + vanilla JS/CSS.

## Features
- 💘 Love compatibility score based on names & birthdays
- ♈ Zodiac sign compatibility
- 🔥 Passion, Trust, Chemistry & Bond breakdown
- ✨ Animated UI with cursor trail, 3D card tilt, floating hearts
- 💌 Share your results
- 📱 Fully responsive

## Tech Stack
- **Backend:** Python / Flask
- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Fonts:** Cormorant Garamond + Inter

## Run Locally

```bash
pip install flask
python app.py
```

Then open [http://127.0.0.1:5000](http://127.0.0.1:5000)
